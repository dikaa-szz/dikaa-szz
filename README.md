## 🚀 Proyek Unggulan

### 01. Sistem Pengaduan dan Monitoring Perbaikan Fasilitas Umum

Aplikasi untuk membantu masyarakat melaporkan kerusakan fasilitas umum dan memantau status penanganan laporan.

**Fitur utama:**
- Pengiriman laporan beserta foto dan lokasi.
- Pemantauan status laporan.
- Dashboard admin untuk mengelola dan memverifikasi laporan.
- Visualisasi lokasi laporan pada peta.

**Teknologi:** Flutter, Firebase, Laravel, React.

[📂 Lihat Repository](https://github.com/dikaa-szz/app_pengaduan1)

---

### 02. Aplikasi Pemesanan air minum

Aplikasi mobile yang dikembangkan untuk mendukung pengelolaan sampah dan mempermudah proses layanan pengambilan sampah.

**Fokus pengembangan:**
- Aplikasi mobile berbasis Flutter.
- Integrasi Firebase untuk kebutuhan data aplikasi.
- Pengembangan fitur layanan dan informasi bagi pengguna.

**Teknologi:** Flutter, Firebase.

[📂 Lihat Repository](https://github.com/dikaa-szz/aplikasi_pemesanan_air_minum)

---

### 03. Sistem Informasi Showroom Mobil

Aplikasi web untuk mendukung pengelolaan data kendaraan dan operasional showroom mobil.

**Fokus pengembangan:**
- Pengelolaan data kendaraan.
- Pengembangan antarmuka web dan backend.
- Integrasi database untuk penyimpanan data.
- Pengelolaan informasi kendaraan melalui sistem web.

**Teknologi:** Laravel,Blade,PHP, MySQL.

[📂 Lihat Repository](https://github.com/dikaa-szz/paskah-mobil)

### 04. Website Showrom
